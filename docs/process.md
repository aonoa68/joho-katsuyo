# 過程が残る道具を使う

この授業が道具を選ぶときの基準は、**たった一つ**です。

!!! quote ""
    **あとからもう一度、同じ結果を出せるか。**

出せないなら、その結果は確かめられません。**確かめられないものは、根拠になりません。**

!!! tip "実際に数えました"
    **[第6回の課題を、同じようにExcelでやってみた記録](week06-excel.md)**

    言葉で言うだけでは確かめられないので、**同じ課題を両方でやって、手数を数えました。**
    差が出たのは「Excelは手数が多い」ではなく、**過程を残す作業と、やり直しの回数**でした。

---

## 同じ表を作る、2つの道

クロス集計表を作るとします。やり方は2つあります。

| | やり方 | できるもの | 残るもの |
|---|---|---|---|
| **A** | 画面の上で項目をドラッグする（ピボットテーブルなど） | 表 | **何も残らない** |
| **B** | コードを書く | 表 | **どの列を、どの条件で、どう数えたか** |

**出てくる表は同じです。**違うのは、半年後のあなたと、報告書を読む人が、**その数字を確かめられるかどうか**です。

Aで作った表について「この数字、どうやって出したんですか」と聞かれたら、答えられるのは記憶だけです。**記憶は残りません。**

---

## 確かめられると、何が違うのか

**1. 自分が間違いに気づける**

間違いは必ずします。問題は、間違えたかどうかではなく、**あとから気づいて直せるかどうか**です。
手順が残っていれば、どこで間違えたかをたどれます。残っていなければ、最初からやり直すしかありません。

**2. 他人が確かめられる**

報告書も発表も、読む人・聞く人がいます。
**「どうやって出したのか」に答えられない数字は、読む人にとっては無いのと同じです。**

**3. やり直せる**

回答が10件増えた。おかしな1件を除いて計算し直したい。
手順が残っていれば、**もう一度実行するだけ**です。手作業なら、また最初からです。

!!! tip "速さを捨てる話ではありません"
    1回で終わるなら、マウスで作るほうが速いです。
    でも調査は**必ずやり直します。**やり直す回数まで数えると、残っているほうが速く終わります。

---

## 🔴 見分け方は、一つだけ

!!! warning ""
    **「これをもう一度出してください」と言われて、手順を人に渡せますか。**

| | 例 |
|---|---|
| **渡せる** | コード、数式、書き残した手順 |
| **渡せない** | 「ここをドラッグして、こう選んで……」と口で説明するしかないもの<br>**手で打ち直した数字**（打ち直した時点で、元データとのつながりが切れます） |

この授業で「**数字を手で打ち直さない**」と何度も言うのは、このためです。

---

## 🔴 「ポチポチ」は、修行ではない

セルを一つずつクリックする。コピーして、貼る。また一つクリックする。目で見て確かめる。
これを何百回も繰り返す作業を、**「慣れ」とか「修行」と呼ぶことがあります。**

**違います。**

コンピュータは、**同じことを繰り返すのがいちばん得意**です。
その繰り返しを人間がやっているなら、それは**本来コンピュータがやるはずの処理を、人間が体で肩代わりしている**ということです。

!!! quote ""
    **人間が「物理マクロ」にされている。**

これは、あなたの能力の問題ではありません。
**道具の側が、やり方を書き残せる形になっていない**ので、人間が毎回その場で手を動かすしかなくなっているだけです。

- 100件なら、気合でどうにかなります
- **1,000件になったら、終わりません**
- **データが1件増えただけで、また最初から全部やり直し**です

コードで書けば、1,000件でも一瞬で、しかも**次も同じことができます。**

**覚えるのは、楽をするためではありません。人間がやらなくていいことを、人間がやらないためです。**

### 苦労した時間の長さは、身についたことの量ではありません

手作業を繰り返すこと**そのもの**に、精神的な値打ちはありません。
**それを「高度な内容を習得した」と言い換えるのは、もう時代に合いません。**

高度かどうかを決めるのは、**何を考えたか**です。**何回クリックしたか**ではありません。

- クリックの回数を減らすために、**何を自動化できるかを考えた** → 高度
- クリックの回数を、**根性で耐えた** → それは耐えただけです

## AIにも、同じことが当てはまります

!!! quote ""
    **支配されているかどうかは、道具の種類では決まりません。出口があるかどうかで決まります。**

Excelでも、AIでも、基準は同じです。**やめても同じことを続けられるなら、支配されていません。**

AIの答えも、**結果だけを受け取れば、過程は残りません。**

だからこの授業では、AIを禁止するのではなく、**確かめられる形で使います。**

- **やり取りを貼る**（第7回以降、課題の1点）── 何をどう聞いたかが残ります
- **同じ数字を、別の道でも出して突き合わせる**（第6回・第7回）── 一致すれば、少なくとも書き間違いではありません

AIを疑っているのではありません。**自分の手で出した数字も、同じように確かめます。**

---

## 誤解しないでほしいこと

- **マウスで操作する道具が悪い、という話ではありません。**見るだけ・探すだけなら、そのほうが速いです
- **Excelが悪いという話でもありません。**（[なぜExcelを使わないのか](tools.md#excel)）
- **全部コードで書け、という話でもありません。**人に渡せる形で残っていれば、何でも構いません。手順を文章で書き残すのでも十分です
- **Pythonを覚える話でもありません。**コードはAIに書かせて構いません（[Python は覚えなくていい](tools.md#python)）。残すために書くのであって、書けるようになるために書くのではありません

!!! note "これは、できる・できないの話ではありません"
    同じようなノートブックを、**都内の高校生に使ってもらったことがあります。全員が動かせました。**
    特別な訓練を受けた生徒ではありません。**才能や適性の問題ではない**ということです。

    差がつくのは一点だけです。**手を動かしたか、画面を見て止まっていたか。**
    止まったまま黙っているのが、いちばん時間を失います。
    AIでも、隣の人でも、TAでも、**聞く相手はどれでもかまいません。**

## この授業では、ここに出てきます

| 回 | やること |
|---|---|
| 第6回 | 同じ数字が、2通りの方法で出るか確かめる（→ [Excelでやると何が増えるか](week06-excel.md)） |
| 第7回 | ピボットテーブルを使わずにクロス集計表を作る／同じ表を2通りの書き方で作って照合する |
| 第11回 | ページを公開する（図のもとになった数字と、件数を添える） |
| 第13回 | 報告書に、**どうやって出した数字か**を書く |

半年かけて同じことを繰り返します。**「出てきた答えを、そのまま信じない」**ための、具体的なやり方です。
