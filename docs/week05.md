### 設問の作りで、同じ間違いが多かったところ

!!! warning "① 数字で聞くなら、単位と記入例を書く"
    「（例：50000円）」のように**例に単位を入れると、「50000円」と書く人が出る。**
    「5万」「50,000」「二十歳」が混ざると、**平均も散布図も出せない。**

    **書き方**：「**半角数字のみ。単位は書かない（例：50000）**」

    **使わない人・していない人の書き方も決めておく。**「していない人は **0** と書いてください」。
    空欄のままだと、**0なのか、答えなかったのかを区別できない。**

!!! warning "② 時刻は、数字で聞いてはいけない"
    「普段、何時ごろに寝ますか（〇時）半角数字のみ」で集めると、次の3つが同じ列に混ざる。

    - **「10」** … 夜10時のつもりで書く人。本人の意図は22時である
    - **「1」** … 深夜1時。数値として並べると、**22時の人より「早寝」になる**
    - **「22時半」** … 書けない。22と23のどちらに寄せるかが人によって変わる

    **時刻は、数えられる量のように見えて、24時で0に戻る量である。**
    平均を出すと、**夜型の人が多いほど平均が早くなる。**調べたいことと逆の結果が出る。

    **選択肢にするのがいちばん確実である。**
    「21時より前／21時台／22時台／23時台／0時台／1時台／2時以降」。

!!! warning "③ 選択肢は「モレ」と「ダブり」の両方を見る"
    **モレ＝当てはまる人がいない。**

    - 「1年・2年・3年・4年」だけ → **4年以上・編入生・科目等履修生・情報TAが選べない**
    - 「はい・いいえ」だけ → **わからない人、判断がつかない人が選べない**
    - ジャンルや理由に「**該当なし**」がない → **その行動をしない人が答えられない**
    - 片方の設問にだけ「**全く使用しない**」がない

    **ダブり＝2つに当てはまる。**

    - 「電子マネー」と「交通系」 → **Suicaはどちらにも入る**
    - 「全く感じない」と「現金と変わらない」 → **同じことを指している**
    - 「北星学園大学の学生」と「大学生」 → **同時に当てはまる**

    **モレよりダブりのほうが厄介である。**モレは「その他」で拾えるが、**ダブりは集計した後では元に戻せない。**
    同じ考えの人が別の選択肢に割れるので、**どちらの人数も実際より少なく見える。**

!!! warning "④ 順序のある選択肢は、順番に並べる"
    「現金／どちらかといえば現金／**キャッシュレス／どちらかといえばキャッシュレス**」は、3番目と4番目が逆である。

    **選択肢の並び順そのものが、データの意味になる。**
    CSVに出すときも、グラフの横軸も、この順番がそのまま使われる。

    直すときは、**文字を書き換えるのではなく、選択肢をドラッグして並べ替える。**
    **すでに答えた人がいる場合、文字を書き換えると、その人の回答の意味が変わってしまう。**

!!! warning "⑤ 比べる2つの設問は、目盛りをそろえる"
    現金の頻度が**4段階**、キャッシュレスの頻度が**5段階**だと、**その2つは比べられない。**
    並べたグラフが同じ形に見えても、中身がちがう。

    **向きもそろえる。**ある設問は「満足していない→満足している」、別の設問は「そう思う→そう思わない」と
    途中で向きが変わると、答える人は気づかずに**逆の位置を選ぶ。**

!!! warning "⑥ 「複数選択可」と書いたら、複数選べる作りにする"
    文言だけ「（複数選択可）」で、**実際は1つしか選べない**設問があった。
    **文言を「最も当てはまるもの1つ」に直すか、設問を「複数回答」にするか、どちらかにそろえる。**

    なお、**複数回答にすると集計の手間が増える。**
    CSVの1つのセルに「スマホ;動画;課題」のようにまとめて入るため、数えるにはセルを分ける作業が必要になる。
    **迷うなら、1つだけ選ばせるほうが楽である。**

!!! tip "依頼文に入れる4つ（手本を読み上げる）"
    **① 何を調べるのか ② 匿名で、個人は特定されないこと ③ 第11回（12/11）に結果をウェブで公開すること ④ 答えたくない設問は飛ばしてよいこと**

    - 「回答は自由意志のもとで行われるため、何らかの理由で回答しにくい方は、**回答を拒否、あるいは途中で中止することができます**」
    - 「集計結果を授業で公開します。**個人の回答が分かる形では公開しません**」

## 課題

- 課題5 回収記録＋不足や偏りの考察（5点）
- 提出期限：**次回授業の開始まで**（遅れた場合は50%）

!!! warning "課題5は**班で1つ**、課題4は**二階建て**です"
    **課題5は、班の代表者が1人だけ提出してください。**提出する人は、**本文の最初に班の番号と全員の名前**を書いてください。
    評点とコメントは、**班の全員に同じものが入ります。**

    **課題4は2つに分かれています。**

    - **グループで1件**：回答者用URL・設問の対応表・第3回から直したところ（代表者が1人）
    - **各自で2枚**：日本語のグラフの画面と、`renshu.csv` を読み込めた画面
      （**班の代表では代えられません。1人ずつ出します**）

    **各自の2枚を出していない人は、第6回（11月5日・11月6日）の画面をそのまま出してください。1点足します。**

**出すものは3つである。**

1. **回収記録**：誰に・いつ依頼し、**何件返ってきたか**
2. **不足の考察**：足りない理由と、**どんな人が抜けたか**
3. **偏りの考察**：集まった回答が、どこに寄っているか

**件数が目標に届かなくても減点しない。**足りない理由を書くほうが評価される。

!!! info "評点の内訳（5点）"
    | | 点 | 見るところ |
    |---|:--:|---|
    | **回収記録** | 1 | 誰に・いつ依頼し、**何件返ってきたか** |
    | **不足の考察** | 2 | 足りない理由と、**どんな人が抜けたか**（下の (a)(b) のどちらでもよい） |
    | **偏りの考察** | 2 | 集まった回答が、どこに寄っているか（下の3つのどれかが1つ書けていればよい） |

    **件数の多さでは点を付けない。**100件集めて考察が1行の提出より、**20件で理由を書いた提出のほうが点は高い。**

!!! tip "「不足」には2種類ある"
    **(a) 件数の不足**：依頼したのに返ってこなかった。
    見るのは人数ではなく、**どんな人が返さなかったか**である（学年・関係の近さ・依頼の仕方）。

    **(b) 特定の設問だけ答えられていない**：ほかの設問には答えているのに、そこだけ空欄が多い。
    **これは調査票の問題である。**聞き方・選択肢・答えたくない内容のどれかが原因になっている。
    **(b) のほうが、次に直すところがはっきりする。**

!!! tip "「偏り」は、全員が同じ回答のことではない"
    次のどれかが見つかれば、それが偏りである。

    - 選択肢のどれかに**大きく寄っている**
    - **答えた人の属性**が一方に寄っている（1年生ばかり、同じ学部ばかり）
    - 聞いた時間帯や場所によって、答える人が決まってしまっている

    **偏りが見つからないときは、「どの範囲でなら偏っていないと言えるか」を書く。**
    1年生にしか配っていないなら、学年の偏りが見えなくても
    「**1年生の中では偏っていない**」としか言えない。ここまで書けていれば十分である。

### 締めたら、CSVに出して大学アカウントへ

**回収を締めたら、その日のうちにCSVを作る。**次回、これをColabに読み込む。

**自分の班がどちらで作ったかを確認してから進める。**編集画面の上に「質問／回答／設定」の3つのタブが並んでいればGoogleフォームである。

**Googleフォームの場合**

1. 編集画面の「**回答**」タブを開く
2. 右上の「**⋮**」（縦の三点）→「**回答をダウンロード（.csv）**」
3. **ZIPで落ちてくる。**ダブルクリックして解凍すると、中にCSVが入っている
4. そのCSVを**大学アカウントのOneDrive**に置く（共有はグループのメンバーと教員だけ）
5. **フォーム側に残っている回答を消す**（「⋮」→「**すべての回答を削除**」）。5までやって、はじめて移したことになる

**Microsoft Forms の場合**

1. 「**応答**」から「**Excel で開く**」
2. **ここで開くのはブラウザ版のExcelで、「名前を付けて保存」がない。**次のどちらかでPCのExcelに持ってくる

    - 「**編集**」→「**デスクトップ アプリで開く**」
    - または「**ファイル**」→「**名前を付けて保存**」→「**コピーのダウンロード**」でPCに落とし、そのファイルをExcelで開く

3. 「**名前を付けて保存**」→ 形式を **CSV UTF-8** にする（置き場所はそのままOneDriveでよい）
4. フォーム側の回答は消さなくてよい。大学のアカウントの中にあるため

**Excelのまま持っていかない。**CSVは中身が文字だけで、メモ帳でも開ける。
どのソフトでも読める形に出しておく。**これが「出口を持つ」ということである。**

!!! warning "文字が化けても、壊れてはいない"
    GoogleのCSVは**UTF-8**である。これをExcelでそのまま開くと日本語が化けることがあるが、**ファイルが壊れたわけではない。**次回Colabに読み込むぶんには問題ない。
    中身を見て確かめたいだけなら、メモ帳やテキストエディタで開く。

!!! note "Googleフォームで集めたグループへ"
    **上の5までやって、はじめて置き場所を移したことになる。**元のフォームに回答が残っていれば、移していない。
    理由は第2回で話したとおり。預かった回答を、自分の私物のアカウントに残さないため。

!!! tip "困ったら"
    **操作方法で困ったときは、**まずAIに聞いてください。それでも解決しないときは、TAか教員に声をかけてください。
    「どこまでできて、どこで止まったか」を言えると、答えが早く返ってきます。

    **ただし、調査してよい内容か・個人情報をどう扱うか・公開してよいかは、教員に確認してください。**
    実際の回答データや個人が分かる情報を、教員の確認なくAIに入力しないでください。
