## つまずきやすいのは、この3つ

**この3つは、TAが先に同じ課題を解いて、実際に詰まったところです。**先に知っておけば、ここで時間を使わずに済みます。

### ① CSVをどこに置くか

Colabの**左端のフォルダのアイコン（📁）**をクリックすると、枠が開きます。**そこにCSVをドラッグする**だけです。

**開いた最初の場所に置いてください。**別のフォルダを開いてしまうと、どこに置いたか分からなくなります。
置けるとファイル名が一覧に出ます。`pd.read_csv("ファイル名.csv")` に書く名前は、**その一覧の名前と1文字もちがわない**ようにします。

!!! warning "置いたファイルは、しばらく経つと消えます"
    Colabはつなぎ直すと、置いたファイルが消えます。**壊れたのではありません。**もう一度ドラッグすれば戻ります。
    消えて困るものを、ここに置いたままにしないでください。

### ② 列名に改行が入っている

フォームの設問文が長いと、**CSVの列名に改行がそのまま入ります。**
見た目は「睡眠時間」でも、本当の列名は `睡眠時間\n（半角数字で）` だったりします。だから

```python
mydf["睡眠時間"]      # → KeyError で止まる
```

**まず、列名を全部出して見る。**

```python
print(mydf.columns.tolist())
```

`'睡眠時間\n（半角数字で）'` のように `\n` が見えたら、それが改行です。**1行で消せます。**

```python
mydf.columns = mydf.columns.str.replace("\n", "", regex=False).str.strip()
```

**列名を見ないまま列を指定するのが、いちばん多い詰まり方である。**
エラーが出たら、まず `columns` を出す。これはAIに聞く前にできます。

### ③ 文字が化けても、壊れてはいない

**Colabで読み込むぶんには化けません。**化けるのは、同じCSVを**Excelで開いたとき**です（第5回で話したとおり、GoogleのCSVはUTF-8です）。

CSVをExcelで保存し直した場合だけ、読み込みに1つ足します。

```python
mydf = pd.read_csv("ファイル名.csv", encoding="utf-8-sig")
```

## やること

- きれいなデータ（1行1件・1列1変数・結合しない・色で意味を持たせない・単位を混ぜない）
- **汚い表を読み込ませて、失敗を見る**
- CSVを読み込む（**コードはAIに書かせてよい。ただし読んで、何をしているか説明できること**）
- 欠測値と外れ値／基本統計量を出す
- **同じ調査をもう一度やったら、同じ数字が出る？**（少ない人数で平均を出すと、毎回ちがう数字が出ることを見ます）
- 同じ数字が3通りの方法で出るか確かめる
- 授業末20分：**ふりかえりテスト**（成績には入りません。終わったらその場で解説します）

!!! tip "新しいデータを受け取ったら、計算の前に最小値と最大値を見る"
    今日のデータには、**体重が −999g の霊長類**が入っています。`-999` は「測定していない」という**符号**です。
    これを見落とすだけで平均が34%ずれます。**しかもエラーは出ません。**グラフも描けます。

    `describe()` を見て、ありえない値（負の体重、300%の割合）がないかを確かめる。**これだけで多くの事故が防げる。**
