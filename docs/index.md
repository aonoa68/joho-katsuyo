# 情報活用

北星学園大学「情報活用／情報活用Ⅰ」（2026年度後期）の授業資料ページです。

この授業は、**半年かけて一つの調査をやり切ります。**テーマを決め、質問を作り、集め、集計し、読み解き、公開して、報告書にまとめます。

!!! note "この授業で大切にしていること"
    ゴールは「ソフトの操作を覚えること」ではありません。操作は、必要になったらAIに聞けばできます。

    大切なのは、**何を確かめたいのかを決める力**と、**出てきた答えをそのまま信じずに確かめる力**です。

!!! warning "シラバスと違うところ（第1回で説明します）"
    シラバスは全クラス共通の文面です。**このクラスでは次の点が違います。**

    - **定期試験はありません。**成績は課題13本（100点）だけで決まります
    - **Word・Excel・PowerPointは使いません。**前期「情報入門」で経験済みなので、次に進みます
    - **教科書は開きません。**資料はすべてこのサイトに置きます
    - 使うのは **Forms・Python（ブラウザ上）・HTML**。パソコンへのインストールは不要です
