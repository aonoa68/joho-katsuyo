# 第2回 資料：どこまで言えるか

**問い：友達20人に聞いた結果を「大学生は〜」と言っていいか。**

**問題は人数だけではない。「友達を選んでいる」ことのほうが大きい。**
同じ選び方のまま人数を増やしても、選び方による偏りは消えない。

---

## 1. 全部は聞けない

知りたいのは「大学生」のことでも、実際に聞けるのは一部の人だけである。

| 用語 | 意味 | 例 |
|---|---|---|
| **母集団** | 本当に知りたい人たちの全体 | 北星の学生全員／日本の大学生／10代・20代／日本に住んでいる人 |
| **標本（依頼対象）** | 母集団から、**調査対象として選んだ人たち** | この授業のクラス40人 |
| **回答者** | そのうち、**実際に答えた人たち** | 返ってきた20人 |

**選んだ人と、答えた人は別である。**40人に依頼して20人が答えたなら、
標本は40人、回答者は20人、回収率は50%。**この区別が、あとで効いてくる**（§3）。

**母集団は「北星の学生」とは限らない。**「日本の大学生はどうなのか」を知りたいなら母集団は日本の大学生であり、
そのとき標本はこのクラスの40人になる。**母集団を大きく取るほど、計画書の 2-(c)「どんな人が抜けるか」に書くことが増える。**
どちらが正しいということはない。**自分がどちらを知りたいのかを、先に言葉にする。**

**集計が直接示すのは、実際に答えた人たちの結果である。**母集団について述べるには、
**対象者の選び方・非回答の影響・推定に必要な前提**を検討する必要がある。
標本から母集団を推定すること自体は、統計の中心的な目的である。**できない、という話ではない。**

**ただしこの授業では、便宜的に回答者を集める。**そのため、
**「大学生全体の傾向である」とは断定しない。**

### だから最初に決めることは1つ

> **誰のことを知りたいのか。**

ここが決まっていないと、「何人集めればいいか」も「誰に聞けばいいか」も決まらない。

## 2. 選び方には名前がついている

| 対象の決め方 | どうやるか | 特徴と注意点 |
|---|---|---|
| **全数調査** | 対象となる全員を調べる | **一部だけを選ぶことによる誤差はない。**ただし調査漏れ・未回答・誤回答は起こりうる |
| **単純無作為抽出** | 名簿から**くじ引き**で選ぶ | 恣意的な選び方を避けられ、**標本抽出に伴う偶然の誤差（標本誤差）を評価できる。**ただし非回答の問題は残る |
| **層別抽出** | 学部などに分け、それぞれから無作為に選ぶ | 各層の人数を確保でき、推定の精度が上がることがある。全体を集計するときは**抽出率に応じた重み付け**が要ることがある |
| **多段抽出** | 学部→クラス→学生と段階的に無作為に選ぶ | 名簿の準備や調査の手間を減らせる。**推定では段階的な選び方を考慮する必要がある** |
| （**便宜的な集め方**） | 近くにいる人・友人・SNSで回す | 実施しやすいが、**母集団全体への一般化には強い制約がある** |

**これは「良い順」ではない。**層別抽出はあらゆる偏りを防ぐ方法ではないし、多段抽出は「そこそこの方法」でもない。
層別と多段は**組み合わせて使うこともできる。**

**この授業でやるのは、いちばん下である。**それでよい。ただし、**そう書く**。

> 「本調査は、担当教員の授業の履修者40名を対象としたものであり、大学生全体の傾向を示すものではない」

**この一文が書ける人の調査は、信用される。**

## 3. 2つの偏り

### 選択バイアス ── 誰に聞いたか

「学食の満足度」を**学食の前で**聞けば、学食を使う人ばかりが答える。使わない人（＝いちばん不満かもしれない人）は最初からいない。

**サークルの紹介ページによくある例**

> 「入会者の90%が満足と回答」

**今も在籍している人**に聞いた数字であることが多い。**やめた人は数に入っていない。**

### 非回答バイアス ── 誰が答えなかったか

**答えなかった人は、答えた人と違う特徴を持っているかもしれない。**
その違いが**調べたい内容に関係していると**、答えた人だけの集計は偏る。
非回答があれば必ず偏る、というわけではない。**関係しているかどうかを考える。**

!!! note "担当教員の経験から"
    前期の授業で、うまく進んでいない学生を早めに見つけようとして、**自己申告のアンケート**を配ったことがある。

    結果はうまくいかなかった。**いちばん支援が必要な学生ほど、アンケートに答えない。**
    授業に来られていない人は、アンケートにも来ない。

    「困っている人は手を挙げてください」という方法は、**手を挙げられる人しか拾えない。**

**回収率を必ず記録する。**50人に依頼して20人が答えたなら、回収率は40%。
**答えなかった30人がどんな人か**を考える。

**依頼した相手と、実際に答えた人は別物である。**計画書でも分けて書く。

| 言葉 | 指すもの | 例 |
|---|---|---|
| 標本（依頼対象） | 調査対象として選んだ人 | 50人 |
| 回答者 | 実際に答えた人 | 20人 |
| 回収率 | 回答者 ÷ 標本 | 40% |

**SNSで広く募集した場合は、何人に届いたか分からないので回収率を計算できない。**
そのときは「計算できない」と、その事情を記録する。

**回収率だけでは、偏りの有無も大きさも分からない。**記録は出発点であって結論ではない。

## 4. 聞いてはいけないこと・守ること

調査は、答えてくれる人の時間と情報をもらう行為である。

### この授業では扱わない

回答者の負担や情報漏えいのリスクを避けるため、**この授業では次を調査しない。**

- 病歴・信条・家計の詳細など、**特に慎重な扱いを必要とする事項**
- 個人が特定できる情報（氏名・学籍番号）を、必要がないのに聞くこと

**研究一般で禁止されている、という意味ではない。**こうした事項を扱う調査では、
目的・必要性・リスク・説明と同意・保護措置を慎重に検討したうえで実施する。
**この授業では、そこまでの手続きを取らないので扱わない。**

### 伝える

- **何のための調査か**
- **答えるかどうかは自由**であること（**設問ごとに答えなくてよい**）
- **どう使い、いつ消すか**
- **集計結果を第11回でウェブに公開すること**

### 守る

- **目的外に使わない**（授業のために集めたデータを、別のことに使わない）
- **ねつ造・改ざん・盗用をしない。**都合の悪い回答を捨てない
- **保管と廃棄**を決めておく

## 5. 🔴 データをどこに置くか

**これが、この授業でいちばん事故が起きやすいところである。**

集めた回答は、**答えてくれた人の情報**である。自分のものではない。

| | |
|---|---|
| **置いてよい** | **大学アカウントのOneDrive。**共有は**グループのメンバーと教員だけ**に限る／Moodleの提出 |
| **置いてはいけない** | **公開されるウェブページ**／誰でも見られる共有リンク／SNS／**自分のPCだけ**／**個人のクラウドアカウントに置きっぱなし** |

### なぜ大学アカウントなのか

**集めた回答は、卒業したあとも残るからである。**

個人のGoogleアカウントやスマホに置いたままにすると、**同級生の回答が、あなたの私物のアカウントに残り続ける。**
大学はそこに手を出せない。あなたが卒業しても、アカウントを放置しても、誰も気づかない。

大学アカウントのOneDriveなら、**卒業時にアカウントごと止まる。**
預かったものを、預かった場所に置いて、期限が来たら終わる。これが筋である。

### 回収が終わったらOneDriveへ移す

**フォームはGoogleでもMicrosoftでも、好きなほうを使ってよい。**
ただし、**回収が終わったらCSVを書き出して、大学アカウントのOneDriveに置く。**

1. フォームの回答をCSVで書き出す
2. **大学アカウントのOneDrive**に置く（グループと教員だけに共有）
3. フォーム側に残っている回答（スプレッドシートやExcel）は**消す**

**3を忘れると、1と2をやった意味がない。**元が残っていれば、置き場所を変えたことにならない。

### フォームの設定を確認する

**どちらを使う場合も、匿名で集める。**

| | 確認すること |
|---|---|
| **Googleフォーム** | **メールアドレスの収集がオフ**になっているか（既定はオフ）／**「結果の概要を表示する」をオフ**にする。オンだと回答できる人が全員の回答やグラフを見られる |
| **Microsoft Forms** | **「名前を記録する」をオフ**にする。**組織内に限定すると、既定で氏名が記録される。**ここを見落とすと、匿名で集めるという約束が最初から崩れる |

**Microsoft Forms を使う人は、必ず1件テスト回答をして、氏名の列が出ていないことを自分の目で確かめること。**

第11回で成果物のページを公開する。**公開できるのは、集計したあとの表とグラフである。**

**ただし「集計したから公開してよい」とは限らない。**

- 該当者が1人しかいない区分は、その集計値から**本人の回答が分かってしまう**
- 散布図で**1点が1人**を表していれば、グラフにしただけでは守れていない
- 他の情報と組み合わせて特定できないかも考える

**公開してよいのは、個人の回答が推測できないことを確認した集計結果だけ。**
人数の少ない区分、珍しい属性の組み合わせ、個人の値が見える図は、
**区分をまとめる・出さないを検討し、教員の確認を受ける。**

- 回答データ（CSV）は公開しない
- **自由記述はそのまま載せない。**内容から本人が特定されることがあり、
  答えた人が想定していない形で公開されることになる

## 5.5 AIに聞いてよいこと・教員に確認すること

操作で困ったときは、まずAIに聞いてよい。**ただし次は教員に確認する。**

- **調査してよい内容かどうか**
- **個人情報をどう扱うか**
- **公開してよいかどうか**

**実際の回答データや、個人を特定できる情報を、教員の確認なくAIに入力しない。**
大学のCopilotにデータ保護の仕組みがあることと、**調査データを入れてよいことは別の話**である。

## 6. 卒業：1文で書く

自分の調査について、**次の1文を書けるようにする。**

> 「この調査で言えるのは（　　　）までであり、（　　　）については言えない。」

書けないなら、まだ**誰に何を聞くのかが決まっていない。**
