# 第9回 資料 同じ概念を、Excelではどう扱っているか

**この回でやる「グラフ」と「散布図」は、Excelにも同じものがあります。**
名前と既定値がちがうだけです。**どちらが優れているかの話ではありません。**

!!! info "これは補習です（成績には入りません）"
    **読まなくても課題9は出せます。**課題9に出すものは変わりません。

    ここに置いたのは、**「Excelならどうやるのか」を並べて見るため**です。
    片方しか知らないと、「そういうものだ」で終わってしまいます。

## 1. 概念の対応表

| この回でやること | Excel | ノートブック（matplotlib） |
|---|---|---|
| 件数を比べる（棒グラフ） | 挿入 → 縦棒／ピボットグラフ | `plt.bar`／`value_counts().plot(kind="bar")` |
| 分布を見る（ヒストグラム） | 挿入 → **ヒストグラム**（2016以降）／分析ツール | `plt.hist(v, bins=15)` |
| 2つの数量の関係（散布図） | 挿入 → **散布図** | `plt.scatter(x, y)` |
| 層別（グループで分けて描く） | 系列を分ける／グラフを複数作る | `for name, g in d2.groupby(by):` の中で `scatter` |
| 相関係数 | `CORREL` | `g[x].corr(g[y])` |
| 軸ラベル | グラフ要素を追加 → 軸ラベル | `plt.xlabel()`／`plt.ylabel()` |
| 凡例 | グラフ要素を追加 → 凡例 | `plt.legend()` |
| 件数（n）を図に書く | テキストボックスに**手で書く** | `plt.title(f"…（n={len(v)}）")` ← **数が自動で入る** |
| 横軸を対数にする | 軸の書式設定 → **対数目盛** | `np.log10(x)` を描く／`plt.xscale("log")` |
| 画像に書き出す | グラフを右クリック → 図として保存 | `plt.savefig("mygraph1.png", dpi=150, bbox_inches="tight")` |
| **日本語を表示する** | 何もしなくても出る | 🔴 **何もしないと □□□ になる** |

    そのままだと、軸ラベルも凡例も**全部 □（豆腐）**になります。

## 2. 🔴 いちばん大事なちがいは、「折れ線」と「散布図」が別のグラフだということ

Excelでは、**横軸が「項目」か「数値」か**で、選ぶグラフが変わります。

| | 横軸の正体 | 点の置き方 |
|---|---|---|
| **折れ線グラフ** | **項目軸** | 並んでいる順に、**等間隔**に置く |
| **散布図** | **数値軸** | **数の大きさどおり**の位置に置く |

Microsoftの説明も「**x の値が数値以外の場合は折れ線グラフ、数値の場合は散布図**」です。

!!! danger "🔴 ここで事故が起きます"
    通学時間と睡眠時間の関係を見たいのに**折れ線**を選ぶと、
    横軸が **1, 2, 3, …** の等間隔になります。**通学時間の大小が軸から消えます。**

    **エラーは出ません。**線がぐちゃぐちゃになるだけです。
    しかも「ぐちゃぐちゃ＝関係がない」と読めてしまうので、**結論まで間違えます。**

ノートブックでは、`plt.scatter(x, y)` も `plt.plot(x, y)` も、**x の値どおりの位置**に置きます。
だからこの取り違えは起きません。かわりに別の形で出ます ――
**散布図のつもりで `plot` を使うと、点が順番に線でつながれます。**
`scatter` が点、`plot` が線です。**道具を変えると、事故の形が変わるだけです。**

## 3. 縦軸が0から始まるかどうかは、グラフの種類で決まります（どちらの道具でも）

`[102, 104, 106, 108, 110]` を描いたときの縦軸（matplotlib 3.10.7 で実行して確認）：

| 描き方 | 縦軸の範囲 |
|---|---|
| `plt.bar` | **0 〜 115.5**（**0から始まる**） |
| `plt.plot`・`plt.scatter` | **101.6 〜 110.4**（**0から始まらない**） |

**Excelも同じです。**縦棒は0から、折れ線・散布図は自動で決まります。

!!! warning "🔴 「Y軸が0から始まっていない悪いグラフ」は、細工とは限りません"
    **同じ数字でも、棒にすると差が小さく見え、折れ線にすると差が大きく見えます。**
    上の例なら、棒グラフでは5本がほぼ同じ高さに見え、折れ線では右上がりの急な線に見えます。

    授業で見た「悪いグラフ」の多くは、**誰かが意図的に細工したものではありません。**
    **道具の既定値のまま作ると、そうなります。**

    だから課題9では「**軸をいじった場合は、その理由を1文で書く**」としています。
    いじらなかった場合も、**縦軸がいくつから始まっているかを自分の目で見てください。**

## 4. ヒストグラムの「山の形」は、道具が勝手に決めています（しかも決め方が別）

| | ビン（区間）の決め方 |
|---|---|
| **Excelのヒストグラム**（既定の「自動」） | **Scottの正規参照規則**でビン幅を計算（Microsoftの説明） |
| **`plt.hist` の既定** | **10本に等分**（データに関係なく10本） |

同じデータ `[1, 2, 2, 3, 3, 3, 4, 4, 5, 10, 30, 50]` で確かめた結果
（matplotlib 3.10.7／numpy 2.4.6）：

| 決め方 | 本数 |
|---|---|
| `plt.hist(d)`（matplotlibの既定） | **10本**（幅4.9） |
| Scottの規則（Excelの自動と同じ考え方） | **3本** |
| Sturgesの規則 | **5本** |

🔴 **同じデータから、3本・5本・10本のヒストグラムが出ます。**
山が1つに見えるか2つに見えるかが、**ここで変わります。**

!!! note "だから本数を書く"
    授業のノートブックは `bins=15` のように**数を書いてあります。**
    自分のデータで描くときも、**読み取りの文に本数を一緒に書いてください。**
    書いていないヒストグラムは、読む人が確かめられません。

## 5. 層別を並べると、縦軸が別々に決まります

A群 `[1, 2, 3, 4, 5]`、B群 `[50, 60, 70, 80, 90]` を**別々に**棒グラフにしたときの縦軸
（matplotlib 3.10.7 で実行して確認）：

| | 縦軸の範囲 |
|---|---|
| A群 | **0 〜 5.25** |
| B群 | **0 〜 94.5** |

**2枚を並べると、棒の高さはほとんど同じに見えます。**実際は10倍以上ちがいます。
**Excelで2つのグラフを作っても、まったく同じことが起きます。**

!!! tip "そろえ方"
    - **Excel**：軸を右クリック → 軸の書式設定で、**最小値・最大値を手で固定する**
    - **ノートブック**：`plt.ylim(0, 上限)` を、**2枚に同じ値で**書く

    どちらでもよいのですが、🔴 **グラフを並べる前に、両方の軸の数字を読んでください。**
    図を見比べる前に、数字を見比べる。これだけで防げます。

## 6. 空欄のある列をグラフにすると

Excelでは、空白セルの扱いを**自分で選びます**。
グラフを選択 → 「データの選択」→ **「非表示および空白のセル」**で、
**「空白」／「ゼロ」／「データ要素を線で結ぶ」**のどれかを選ぶ形です。**既定は「空白」（線が途切れる）**です。

ノートブックは、**描く前に落とします。**授業のテンプレートが

```python
v = mydf[col].dropna()
d2 = mydf.dropna(subset=[x, y, by])
```

で始まっているのは、これです。**落ちた行は、図には出てきません。**

!!! warning "🔴 だから n を書きます"
    どちらの道具でも、**落ちた件数は図を見ても分かりません。**
    図に **`n=38`** と書いてあれば、回収40件という記録と見比べて「**2件落ちた**」と分かります。

    これが「**件数（n）を書く**」のいちばんの効き目です。見栄えの話ではありません。
