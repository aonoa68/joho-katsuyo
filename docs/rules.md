# 授業のルール

## この授業について

半年かけて**一つの調査**をやり切ります。テーマを決め、質問を作り、データを集め、集計し、読み解き、**ページとして公開**して、報告書にまとめます。

---

## 成績評価

**定期試験はありません。**成績は**課題13本＝100点**だけで決まります。

| 区分 | 回 | 点 |
|---|---|---|
| 企画・設計 | 第1〜5回（各5点） | 25 |
| データ処理 | 第6回8点／第7回8点／第8回6点／第9回8点 | 30 |
| 成果物 | 第10回5点／第11回5点／第12回15点／**第13回 報告書20点** | 45 |
| | **合計** | **100** |

- 第14回に課題はありません（成績にも算入しません）
- **報告書（20点）は個人で書きます。**グループの成果物とは別です

## 課題の提出

- 提出期限：**次回授業の開始まで**
- 提出方法：Moodle（**各回のページの「今日のリンク」から開けます**）
- 遅れた場合：**50%**／未提出：0点
- ファイル名：`学籍番号_氏名_課題名`

## 出席

- **欠席は4回まで。5回以上で単位を認定しません**（14回授業のため、5回で3分の1を超えます）
- 「5回まで休める」は誤解です
- パソコンの忘れ・充電切れは貸し出しがありません。その回は参加できなくなります

## グループについて

- **4人**が基本です
- グループ課題には**貢献記録**（誰が何を担当したか）を添えてもらいます
- 発表では、誰がどこを話すかを明示してもらいます

---

## 授業中に守ってほしいこと

- 集めたデータには**他人の回答**が入っています。**公開する場所に置かないでください**（第2回で詳しく扱います）
- 分からないことは、**まずAIに聞く**。それでも解決しなければTA・教員に聞く（[AIとの付き合い方](ai.md)）
- 実習室での飲食は禁止です
