# 第3回 調査票の設計(1)：設問とデータの種類

**10/8・10/9**

## この回の問い

> 質問の作り方で、後からできる分析が決まってしまうのはなぜか

## やること

- データの種類（質的／量的、名義・順序・間隔・比率）
- **この種類ならこの集計・このグラフ**という対応
- 悪い設問を直すクイズ
- Formsで調査票のドラフトを作る

## 課題

- 課題3 調査票ドラフト（5点）
- 提出期限：**次回授業の開始まで**（遅れた場合は50%）

## 次回までにやること

**各設問に「データの種類」を注記**する。答えにくい設問がないか、グループの誰かに読んでもらう

!!! tip "困ったら"
    まずAIに聞いてください。それでも解決しないときは、TAか教員に声をかけてください。
    「どこまでできて、どこで止まったか」を言えると、答えが早く返ってきます。
