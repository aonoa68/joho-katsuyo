## 1. ファイルを入れる前後

| 症状 | 原因 | 直し方 |

| 入れたはずなのに `FileNotFoundError` | 🔴 **思ったのと違う場所に入っている**／**ファイル名の打ち間違い** | 下の「パスをコピーして貼る」。**手で打たない** |

### 🔴 CSVの入れ方と、ファイル名の貼り方

**「入れたはずなのに見つからない」が、いちばん多い。**原因は2つあり、どちらもやり方で防げる。

#### 入れ方 ―― ドラッグしない

🔴 **ファイルをドラッグして落とすのは、やめてください。**
フォルダの上に落ちると、**その中**に入ってしまいます。`/content/○○.csv` のつもりが `/content/sample_data/○○.csv` になり、見つからなくなります。**画面上はどちらも同じように見えます。**

1. 左の **📁**（フォルダのアイコン）を開く
2. 上にある **「セッション ストレージにアップロード」**（↥ のアイコン）を押す
3. CSVを選ぶ

#### ファイル名 ―― 手で打たない

Formsから落としたCSVは `調査(1-37).csv` のように、**日本語・括弧・スペース**が入ります。手で打てば、まず合いません。

1. 入ったCSVの行を **右クリック**
2. **「パスをコピー」**
3. `pd.read_csv("　")` の**引用符の中に貼り付ける**（中身は全部消してから貼る）

```python
mydf = pd.read_csv("ここに貼り付ける")
```

!!! tip "貼り付けたパスを見れば、どこに入っているか分かる"
    `/content/調査.csv` … **正しい場所**にある
    `/content/sample_data/調査.csv` … 🔴 **フォルダの中**に入っている
    （貼ったパスのままでも動きます。気持ち悪ければ、入れ直してください）

**ファイル名を打ち直さない。**これも「数字を手で打ち直さない」と同じ話です。

### 🔴 読み込んだら、まず確かめる

**`read_csv` を押したすぐ後に、これを1回実行する。**30秒で済む。ここを飛ばすと、あとで必ず戻ってくることになる。

入れたはずのCSVの名前が出てこなければ、**まだ入っていない**か、**フォルダの中に入っている。**上の「入れ方」からやり直す。
（`!` で始まる行は、Pythonではなく**コンピュータへの命令**である。詳しくは第9回で。）

```python
# ② 読めたか ―― 行数・列数と、中身の型を見る
```

**③で名前が出るのは、たいてい無害な列である。**Formsの書き出しには `名前`・`最終変更時刻` のような**最初から空の列**が必ず付いてくる。フォームを「クイズ」形式で作った班には、`合計点数`・`クイズのフィードバック`・`フィードバック - ○○` という空の列も付く。**どれも無視してよい。**

**自分が使いたい設問の列が③に出たときだけ**、班で元のFormsを確認する。

| ③の結果 | 意味 | どうするか |
|---|---|---|
| `名前`・`最終変更時刻`・`合計点数` などが出た | Formsが付けた列。**最初から空** | 無視してよい |
| **使いたい設問の列**が出た | その列には回答がない | 班で元のFormsを確認する |
| 回答数が思ったより少ない | 書き出した時点の回答数。**締め切り前のものかもしれない** | 班で、いつ書き出したものか確かめる |

!!! danger "🔴 `head()` の5行だけで「空だ」と決めない"

    5行だけを見れば「この列は空だ」と**判断してしまう可能性がある。**
    空かどうかは、必ず上の `notna().sum()` で数える。

## 2. 列を指定するとき

| 症状 | 原因 | 直し方 |
|---|---|---|
| `KeyError: '○○'`。列名は合っているはずなのに | 🔴 **列名に見えない文字が入っている** | 下の「列名を掃除する」を実行する |
| 列名の表示に `\n` や `\xa0` が見える | 改行とノーブレークスペース。**Formsの書き出しではほぼ必ず入る** | 同上 |
| 表が空（`Empty DataFrame`）になる／件数が全部 `0` になる | 🔴 **区分にまとめた結果を、元の列に書き戻している**（下の §4 を見る）。まれに、その列に回答がない | まず `pd.read_csv` のセルを押し直す。区分は**新しい名前の列**に入れる。回答の有無は `mydf[col].notna().sum()` で数える |

```python
# 列名を掃除する ―― 列を指定する前に、1回だけ実行する
print(mydf.columns.tolist())          # ← まず実物を見る

mydf.columns = (mydf.columns
                .str.replace("\n", "", regex=False)   # 改行を消す
                .str.replace("\xa0", "", regex=False) # ノーブレークスペースを消す
                .str.strip())                          # 前後の空白を消す

print(mydf.columns.tolist())          # ← きれいになったか確かめる
```

## 3. 値の中身

| 症状 | 原因 | 直し方 |
|---|---|---|
| 平均を出そうとして `TypeError: Could not convert string ... to numeric` | **数値の列に文字が混ざっている**（「60」と「60分」） | ① どの回答が原因か**実物を見る** → ② 直す。**いきなり消さない** |
| `value_counts()` で、同じはずの値が2行に分かれる | 🔴 **半角と全角が混ざっている**（`3` と `３`） | **消さずに、半角にそろえる**（`unicodedata.normalize("NFKC", s)`） |
| 並べ替えると、1つだけ変な場所に出る | 同上。全角は数ではなく**文字**なので、後ろか別扱いになる | 同上 |
| 選択肢がラベルごと入っている（「1：全く当てはまらない」） | Formsの選択肢の書き方 | 先頭の数字だけ取り出す／対応表で数値に直す |
| 件数が思ったより少ない | **空欄（NaN）が自動で除かれている** | それでよい。ただし **何件から出した数字かを必ず書く** |

!!! danger "🔴 「数字以外を全部消す」はやってはいけない"
    どの回答が原因かを見ないまま消すと、**消してはいけないものまで消える。**
    順番は **① 犯人を探す → ② 直す。**

## 4. セルを押すとき

| 症状 | 原因 | 直し方 |
|---|---|---|
| ▶ を押しても何も起きない。エラーも出ない | **行の先頭に `#` が付いたまま**。`#` の行は実行されない | 使う行の `#` を消す。**何も起きないのが正常** |
| 書き換えたのに、出力が前のまま | 🔴 **書き換えたあとに ▶ を押していない** | もう一度 ▶ を押す。**出力は、最後に押したときのもの** |
| 2回目に押したら、件数が全部 0 になった | 🔴 **元の列に結果を書き戻している** | **新しい名前の列**に入れる（`mydf["○○_区分"] = ...`）。何回押しても同じ結果になる |
| `NameError: name 'mydf' is not defined` | 読み込みのセルより**前**のセルを押した／**ランタイムが切れた** | **上から順に ▶ を押し直す。**セルの位置が読み込みより前なら、後ろに動かす |

## 5. コードを書くとき

| 症状 | 原因 | 直し方 |
|---|---|---|
| `SyntaxError: invalid non-printable character U+3000` | 🔴 **コードに全角スペースが入っている。**画面では空白にしか見えない | その行の空白をいったん全部消して打ち直す。**行の末尾**に入っていることが多い |
| `SyntaxError: invalid character '”' (U+201D)` など | 全角のクォートやカッコ（`”` `（`） | 半角に打ち直す |

**どちらも、エラーの文をそのままAIに貼れば一発で分かる。**
実際にこのクラスで起きたときも、AIは「行の末尾に全角スペースが入っています」と正しく答えた。

## 6. 🔴 最後に ―― これはエラーが出ない

**AIが出した数字を、自分のセルの出力と見比べずに書き写す。**

これはエラーになりません。画面は何も言いません。**けれど、間違っています。**

実際にこの授業で起きました。**同じデータ・同じ件数なのに、報告された平均が2つあった。**
片方は自分のノートブックで計算した数字、もう片方はAIが出した数字で、**AIのほうが誤っていた。**
手元に出力があれば、その場で気づけた。

> **AIに計算させてよい。**ただし、**自分のセルの出力と見比べてから書く。**
> 見比べられる形で残っていないものは、まだ結果ではない。
